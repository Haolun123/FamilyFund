# Father Fund：独立交易与仓位跟踪

实现日期：2026-11-04。入口为 Dashboard 的 Father Fund 标签页。

## 用户目标与第一版范围

父亲证券账户独立核算，用20%—30%的权益区间跟踪退出及重新配置进度。功能包括期初及历史成交导入、立即保存成交、资金变动、行情/手工估值、调整计划、完整流水导出、撤销/纠错、券商快照对账。暂不提供自动交易、日内风控、自动清仓或完整TWR/最大回撤曲线。

父亲资金、交易和损益不计入原FamilyFund或Son Fund。第一版不自动生成合并风险报表，避免将独立资产重复计入。

## 文件及计算

- 页面：`dashboard/father_tab.py`，由主应用挂到Father Fund。
- 引擎：`src/father_fund.py`；不复用主账户的Cash/Company_Stock外部现金流选择规则。
- 独立数据：默认主数据目录下`father/ledger.csv`，可用`FAMILYFUND_FATHER_DATA`覆盖。
- 输入表：优先`FAMILYFUND_FATHER_INPUT`，其次Obsidian的`familyfund/_father_input.md`，最后数据目录`father/_father_input.md`；缺失时显示随页面打包的空模板。
- 环境中的Obsidian路径由`OBSIDIAN_VAULT_PATH`指定，现有Docker挂载可直接使用。

单个CSV流水为唯一事实源，列为事件编号、记录时间、发生时间、类型、JSON内容。没有“流水保存但持仓表尚未保存”的双文件提交问题。日期统一使用北京时间的无时区ISO时间。按发生时间重放，记录时间保留审计顺序。

事件：OPEN期初、TRADE成交、CASH资金、QUOTE估值、PLAN计划、BROKER券商快照、VOID撤销。修正交易使用同一批次追加VOID与替代TRADE，原记录不删除。撤销引起后续超卖或现金不足时拒绝整个改动，用户应改为能自洽的纠正记录。

每次写入持有独立账户锁，锁内读取现有流水、验证重放、追加并经`nav_engine._atomic_write_csv()`原子写入，再检查行数和内容。继承滚动备份，另在每次覆盖前保留临时原文备份。不会调用主账户transaction.csv写入逻辑。

## 金额语义

- 买入按实际人民币扣款减少现金；卖出按实际人民币净到账增加现金。输入为正数，方向决定正负。
- 费用字段已含在实际收付中，仅用于核对，不能重复扣费。
- 港股成交原价和币种独立保存，市值使用价格×股数×报价汇率；现金使用实际人民币结算，不用后来汇率回算。
- 现金入金/出金才计入外部净流量；股息、利息属于收益，费用属于损失。分红再投资记现金分红与买入两笔。
- 接手以来损益＝当前总资产－期初总资产－外部净入金。使用已保存价格，无日内实时收益保证；不冒充TWR或原券商全历史盈亏。
- 期初价格是基准估值，历史负成本不参与期初资产计算。

## 防错与对账

成交必须有唯一券商编号或自编编号，同一提交事件编号重试幂等。多笔真实相同成交可使用各自编号。禁止负数量、非有限数、无效币种、重复期初、期初前交易、超卖与历史时点负现金。

计划只改变状态。估值只改变价格汇率，保留逐项报价时间；过旧报价不覆盖后来的成交或估值。场内资产使用市场报价路径；场外公募使用基金净值路径，不根据“权益”类别猜测交易场所。行情逐项串行请求，失败项目不覆盖旧值。日级行情的时间标记为该日收盘端点，当日则用获取时刻，界面不声称是精确成交时间。

券商总资产、市值、可用分别保留。可用不自动当作净现金，“市值＋可用－总资产”作为口径差异显示，绝不生成调平收入。对账按券商快照时间重放，后续成交不会与旧快照直接误比；持仓完整清单用于数量核对。报价尚未对齐时，金额差异需要人工解释。

最新用户持仓只预填到Markdown的对账区域；期初日期和净现金未齐前不会创建真实流水。推断的腾讯汇率不作为确认行情写入。

## 验证

引擎测试覆盖含费现金、港币估值与人民币结算分离、重复请求、成交编号、并发追加、原账户隔离、撤销与原子纠正、历史现金校验、报价时点、计划不改持仓、资金流收益分离、Markdown导入及对账。Streamlit AppTest覆盖导入提交、实际成交保存、所有操作页与无效输入。

运行：`python -m pytest tests/test_father_fund.py tests/test_father_tab.py -q`。UI测试需要Streamlit，建议使用现有容器。

2026-11-04验证结果：专项29项通过；完整测试566项通过、28项跳过、20项失败。失败位于本轮未修改的AH/DCA/FI配置、基本面历史缓存、NAV年化契约、资产类别代理及QVIX历史测试；涉及旧路径与现有config/cache目录不一致、旧ETF_Stock分类及年化返回值预期。AH失败已独立复现，本轮未将这些问题混入Father Fund改动。
