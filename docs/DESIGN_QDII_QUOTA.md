# DESIGN: QDII额度管理 + 场内溢价决策

## 设计目标

周内决策辅助工具。回答一个问题：**这周场外额度够不够？不够时场内怎么补？**

输出是操作建议，不是交易记录。用户自主决策执行，执行后在 Weekly Update 里记账。

---

## 定位

- **不在 Weekly Update Tab** — Weekly Update 是周末记账，这个工具是周内看的
- **独立 Tab（暂定 Planning 或新 Tab）** — 信息密度足够独立，逻辑与市场温度计不同
- **合成标普逻辑从 Weekly Update 剥离** — 合成决策（纳指超额→追加道指）在此给出建议，用户执行后再在 Weekly Update 记账

---

## 输入源

| 输入 | 来源 | 说明 |
|------|------|------|
| 场外基金限额 | `data/config/qdii_quota.json` | 用户手动维护，显示最后更新日期提醒复核 |
| 每周基本金额 | `data/config/dca_config.json` | base_amount_cny |
| 矩阵倍数 | `get_market_signals()` 自动读取 | 无需手动输入 |
| ndx_other_weekly / sp_other_weekly | `dca_prepaid.json` config 段 | 其他平台补充定投金额 |
| 实时溢价 | 场内ETF实时价 / 场外基金最新净值 | 拉取时机：用户打开此Tab时 |
| dca_prepaid 余额 | `dca_prepaid.json` dow_prepaid.balance | 道指预付池当前余额 |

## 决策逻辑

### 标普500决策树

```
标普本周目标 = sp_base × 矩阵倍数 + sp_other_weekly
场外可买上限 = Σ(各标普场外基金日限额 × 5)  [limit='关闭'的跳过]

① 场外可买上限 ≥ 目标
   → 场外可买满，无需场内，结束

② 场外买不满，缺口 = 目标 - 场外可买上限
   → 查场内溢价（513650 标普500ETF南方）

   溢价 < 7%？
   ├── 是 → 建议场内513650补缺口
   │        （提示：单笔 ≥ 5000元，否则手续费不划算，可累计到下周）
   └── 否 → 计算纳指超额量
             纳指超额 = max(0, 纳指场外可买上限 - 纳指本周目标)
             纳指超额 > 0？
             ├── 超额 ≥ 缺口 → 建议追加道指买入 = 缺口金额（合成完全覆盖）
             ├── 超额 < 缺口 → 建议追加道指 = 超额金额，剩余缺口本周无法覆盖
             │                  （道指需溢价 < 4%，否则也不建议）
             └── 超额 = 0    → 缺口本周无法覆盖，建议下周优先补入
```

### 纳指100决策树

```
纳指本周目标 = ndx_base × 矩阵倍数 + ndx_other_weekly
场外可买上限 = Σ(各纳指场外基金日限额 × 5)

① 场外可买上限 ≥ 目标 → 无需场内，结束

② 买不满，缺口 = 目标 - 场外可买上限
   → 查场内溢价（513390 纳指100ETF博时）
   溢价 < 11%？
   ├── 是 → 建议场内513390补缺口（单笔 ≥ 5000元）
   └── 否 → 缺口本周无法覆盖
```

---

## 合成标普与纳指超额

**核心原则**：合成标普不绑定特定基金，任何纳指场外可买上限超出纳指本周目标的部分均为"超额纳指"，可用于合成标普敞口。

合成等式：纳指超额 N元 + 道指 N元 ≈ 标普敞口 2N元

道指来源优先级：
1. `dca_prepaid` 余额（已有道指库存）
2. 余额不足则建议额外买场内道指ETF（513400，溢价 < 4%）

---

## 场内溢价阈值

| 指数 | 场内ETF | 溢价阈值 |
|------|---------|---------|
| 纳指100 | 513390 纳指100ETF博时 | < 11% |
| 标普500 | 513650 标普500ETF南方 | < 7% |
| 道指 | 513400 道指ETF | < 4% |

溢价 = (场内价格 - 场外最新净值) / 场外最新净值 × 100%

---

## 场内最小交易金额

单笔 ≥ 5000元。低于此金额手续费比例不划算，缺口可累计到下周。

---

## UI展示要点

- 显示限额表最后更新日期，提醒用户定期复核
- 标普/纳指分两块展示：目标 / 场外上限 / 缺口 / 建议操作
- 溢价实时显示，颜色区分（绿=低于阈值，红=超过阈值）
- 合成标普建议单独一行：超额纳指量 / 建议追加道指量 / prepaid余额
