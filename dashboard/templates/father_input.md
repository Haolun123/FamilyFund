# Father Fund 初始化与对账输入

填写后，在 Dashboard → Father Fund → 初始化导入中预览并保存。也可以把文件内容粘贴到页面。

- 基准时间选在你希望开始管理业绩记录、且持仓和净现金完整可核对的时刻。基准之后的成交只填一次；不要把已经体现在期初数量里的交易再填一遍。
- 日期时间统一为北京时间：YYYY-MM-DD HH:MM:SS。只有日期无法确定同日先后，请按券商记录补时间。
- 数字不加逗号、货币符号或“万”。股票/ETF按股数或份额；人民币资产汇率填1。
- 交易场所填写“场内”或“场外”，决定刷新市场报价还是基金净值；场外基金同样可以归入权益。
- 期初价格是基准时的估值价格，不是历史摊薄成本。无需追溯接手前的全部交易。
- 类别填写：权益、债券、货币、黄金。个股、股票ETF、股票基金和含权益的高风险策略计入“权益”。
- 人民币实际收付：买入填账户实际扣款（含全部费用）；卖出填实际净到账。均填正数。“费用（已含）”仅留作核对，不会再扣一次。
- 港股成交价填港币原价，实际收付填人民币结算金额。报价换汇与实际结算不必完全相同，不能用最新汇率覆盖历史结算。
- 成交编号须唯一，可用券商成交编号；自编时如T001、T002。完全相同的多笔成交也应有不同编号。
- 空白交易占位行可以保留；不要在备注里使用竖线。期初未持有的标的数量填0；首次持有的新标的可自行加行。
- 第5、6节只用于最新对账，不会自动变成期初。可用资金和净现金分开核对。
